# ThirdPersonRPG

언리얼 엔진 5와 C++로 3인칭 RPG의 상호작용 시스템을 구현한 개인 프로젝트

## 개발 문서
[DevLog 전체 보기 (Notion)]
https://cherry-paperback-29a.notion.site/ThirdPersonRPG-388bca612a3d805a9627faca84e2b57b

### 개발 환경 : Unreal Engine 5.7 / Visual Studio 2022 / C++ / GitHub

### 구현 내용

1. Enhanced Input 기반 3인칭 캐릭터 이동 및 시야 조작
2. 인터페이스(IInteractable) 기반 상호작용 구조
3. 구체 오버랩을 통한 상호작용 대상 감지 (라인트레이스에서 교체)
4. 부모 클래스 상속을 통한 상호작용 액터 확장
5. 재화 획득과 소비
6. 상호작용 프롬프트 UI

---

### 작업 방식에 대하여

코드 작성 과정에서 AI(Claude)를 사용
